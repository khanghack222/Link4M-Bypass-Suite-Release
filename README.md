## 🧩 Cài đặt Chrome Extension (Thủ công)

Nếu bạn muốn sử dụng dưới dạng Chrome Extension độc lập:

1. Tải repository về máy hoặc mở thư mục `extension/`.
2. Mở trình duyệt Chrome/Edge, truy cập: `chrome://extensions/`.
3. Bật chế độ **Developer mode** (Chế độ dành cho nhà phát triển) ở góc phải trên cùng.
4. Bấm **Load unpacked** (Tải tiện ích đã giải nén) và chọn thư mục `extension/`.

## 🌟 Tính năng chính

- **Smart Transition Engine**: Tự động nhận diện luồng chuyển hướng đối tác và tối ưu hóa thời gian chờ.
- **Intelligent Verification Monitor**: Giám sát và tự động kích hoạt tiến trình ngay khi nhận được tín hiệu xác thực.
- **Low-Footprint VM Pipeline**: Mã nguồn được đóng gói theo kiến trúc ảo hóa VM, chạy mượt mà không gây giật lag trình duyệt.
- **Zero-Friction Updates**: Tích hợp sẵn Header Auto-Update của Tampermonkey.
